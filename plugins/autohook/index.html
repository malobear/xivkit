About AutoHook

It hooks the fish for you, can you believe it?

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Puni.sh repository addresshttps://love.puni.sh/ment.json
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for AutoHook, and click Install.

AutoHook comes from the Puni.sh repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.

Commands

AutoHook's commands are handy in fishing macros, for example switching preset and bait before you cast. These are the plugin's own descriptions.

Commands can change when the plugin updates.
