Combat Cursor Containment

Keep your mouse cursor contained during combat!

About Combat Cursor Containment

Automatically changes the 'limit mouse operation to game window' setting when entering/exiting combat.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Combat Cursor Containment, and click Install.
