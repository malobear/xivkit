About OBSPlugin

A plugin to control OBS by WebSocket, streaming with any UI modification is not recommended.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for OBSPlugin, and click Install.
