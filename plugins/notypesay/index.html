Tired of typing snae ling? Click instead!

About NoTypeSay

Adds a button on the duty list for /say quests like quest items and emotes have! Compatible with all languages and controllers.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for NoTypeSay, and click Install.
