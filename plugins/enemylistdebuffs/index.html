EnemyListDebuffs

Because tracking your DoTs shouldn't be difficult.

About EnemyListDebuffs

Displays your debuffs on the enemy list. Original implementation credit to aers.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for EnemyListDebuffs, and click Install.
