ComfyLoot

RuneLite inspired drop-tracker

About ComfyLoot

Tracks the contents and market value of items dropped while killing monsters. And drops from some other activities such as dungeons, raids, gathering, and maps.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for ComfyLoot, and click Install.
  4. This one is currently testing-only: turn on testing builds for it in the installer before it will show up.
