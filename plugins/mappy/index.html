About Mappy

Replaces the in-game map with an ImGui implementation with several additional features.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Mappy, and click Install.
