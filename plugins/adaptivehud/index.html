Adaptive Hud

Switches your /hudlayout when your game switches from windowed to fullscreen.

About Adaptive Hud

Useful for ultrawide users, swapping from windowed/fullscreen will automatically switch your hudlayout. /pah to configure

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Adaptive Hud, and click Install.
