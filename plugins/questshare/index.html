Quest Share

About Quest Share

Follow your friends on their questing journey by seeing their progress through a shared quest. Provides markers for quest destinations and (soon) teleporting features.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Quest Share, and click Install.
