How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for RPBlurb, and click Install.
  4. This one is currently testing-only: turn on testing builds for it in the installer before it will show up.
