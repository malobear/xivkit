About Shrinkage

This plugin will shrink and grow characters based on how much health they have, affects you and your party /shrinkage to open the config window.

Can you install it?

Not right now. Shrinkage was last built for Dalamud API 14, and current Dalamud is API 15, so the installer lists it as outdated and won't install it until the author releases an update. In the meantime, the similar plugins below do work.
