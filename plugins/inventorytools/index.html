Allagan Tools My pick

Get organized in FFXIV, easily locate/show where to sort items, plan your crafting, and search for mobs, duties, airships, and submarines!

Why it's on my list

Cross-storage inventory search and filtering across characters, retainers, and the Free Company chest, plus craft planning and marketboard integration right in tooltips. In the default plugin repo

About Allagan Tools

Allagan Tool's primary purpose is to keep track of items across your characters/retainers/free company. With it's filter system you'll never lose track of items or not know where they should be sorted. While this is it's primary purpose, it has quite an exhaustive list of other features including: - Craft planning - Market board integration - Item highlighting in inventories when searching/sorting and picking ingredients for crafts - Item window that includes vendor and source information among other things - Duty/mob/airship/submarine windows that are fully searchable - A filtering system that lets you setup complex searches for specific items - Tooltip integration that'll let you see where the items are on hover

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Allagan Tools, and click Install.
