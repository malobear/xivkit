About Hit it, Joe! (Formerly TF2-ish Critical Hits Plugin)

* Set sounds and flavor text to be played/shown whenever you deal direct or critical damage or heal. * Set sounds to be played when a countdown is in progress. * Use different configurations by job. * Use the game's SFX or your own custom WAV or MP3 files.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Hit it, Joe! (Formerly TF2-ish Critical Hits Plugin), and click Install.
