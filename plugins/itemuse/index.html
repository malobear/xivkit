Item Use

Easily see common item uses.

About Item Use

Displays indicators in the item help popup for when an item is used by leves, GC dailies, etc. to help you decide what is worth keeping, selling, or taking as a reward.

Screenshots

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Item Use, and click Install.
