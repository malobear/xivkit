About V(ery) Island

Automate gathering, workshop assignments, etc.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    https://puni.sh/api/repository/veyn
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for V(ery) Island, and click Install.

V(ery) Island comes from the Puni.sh (veyn) repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
