Steam Recording Enhanced

Add various in-game events to your Steam Game Recording timeline, comes with instructions for non-steam users!

About Steam Recording Enhanced

Enhance Steam Game Recording by automatically adding configurable in-game events to the timeline, allowing for easy rewinding and clipping. Rewind to the moment of your death to reassure yourself that you did dodge the AOE before it went off and that the game does hate you personally with greater efficiency than ever! Non-steam users will have to follow a setup guide located in the configuration's window Status tab to get everything working.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Steam Recording Enhanced, and click Install.
