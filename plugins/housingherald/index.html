About Housing Herald

A Dalamud plugin for FFXIV that reminds the player when the results are in for the house they bid on

Can you install it?

Not right now. Housing Herald was last built for Dalamud API 14, and current Dalamud is API 15, so the installer lists it as outdated and won't install it until the author releases an update. In the meantime, the similar plugins below do work.
