Scriptable overlay engine for drawing mechanics, markers, and indicators in real-time

About Splatoon

Splatoon is a scriptable telegraph and overlay engine for Final Fantasy XIV, built on the Dalamud plugin framework. It allows scripts to draw shapes, markers, labels, and indicators directly in the game world. These overlays can be attached to actors, positions, or events, and are rendered with precise positioning. Splatoon does not include presets or encounter logic by default. If you want presets, you must create them yourself or import them from others. In short, Splatoon draws things. What it draws is up to you!

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    https://love.puni.sh/ment.json
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Splatoon, and click Install.

Splatoon comes from the Puni.sh repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
