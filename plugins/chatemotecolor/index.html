About ChatEmoteColor

A simple plugin that recolors emote chat lines depending on who is executing the emote and their target.

Can you install it?

Not right now. ChatEmoteColor was last built for Dalamud API 8, and current Dalamud is API 15, so the installer doesn't list it at all. It will come back if the author updates it. In the meantime, the similar plugins below do work.
