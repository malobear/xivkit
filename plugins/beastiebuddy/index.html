BeastieBuddy

A searchable mob database with spawn locations for Beastmaster, Blue Mage, or hunts

About BeastieBuddy

A searchable list of all mobs and their known locations, using community data. Use /bbuddy to open, or search with /bbuddy <mob_name>.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for BeastieBuddy, and click Install.
