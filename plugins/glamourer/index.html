Glamourer

Change and save appearance of players.

About Glamourer

Adds functionality to change and store appearance of players, customization and equip. Requires Penumbra to be installed and activated to work. Can also add preview options to the Changed Items tab for Penumbra.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste https://raw.githubusercontent.com/Ottermandias/SeaOfStars/main/repo.json, click the + button, then the save button.
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Glamourer, and click Install.

Glamourer comes from the Sea of Stars repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
