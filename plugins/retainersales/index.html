About Retainer Sales

Quickly see which retainers have sold something while you were logged off.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins and search for RetainerSales. This plugin is hidden from the installer's browse list, so it only shows up when you search its exact internal name.
  4. Click Install.
