[ Any Way the Wind Blows (Fungah) is a Gold Saucer Gate There are variations of AOE patterns that can occur There is no real 'safe spot', but there are spaces where there is less overlap by these potential AOEs One of these spots is marked by this plugin when you are in the GATE ]

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Fungah, and click Install.
