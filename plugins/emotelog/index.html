About Emote log

Adds a window logging all emotes used on you, so you never miss a sneaky dote again.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Emote log, and click Install.
