About Honorific

Assign custom titles to players.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Honorific, and click Install.

Commands and tips

Honorific's settings window has a Commands section with these same commands. The title commands work well in gearset macros, so a title can change with your job.

Also works (not in the help)

/honorific random
Pick a new random title, for characters set to use random titles.

The extra commands and tips are XIVKit's notes, worked out from the plugin's code. Commands can change when the plugin updates.
