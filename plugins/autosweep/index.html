PaissaHouse

Crowdsourced housing alerts and lottery tracking for all.

About PaissaHouse

Looking for that perfect house? PaissaHouse lets you receive notifications when a new plot of land is up for sale on your home world. View the list of all houses available on a world at https://paissadb.zhu.codes/!

Want to contribute? Check out the repository (globe icon below) for instructions.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for PaissaHouse, and click Install.
