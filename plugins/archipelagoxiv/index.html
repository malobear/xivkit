About ArchipelagoXIV

Key Item Randomizer for FFIXV

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins and search for ArchipelagoXIV. This plugin is hidden from the installer's browse list, so it only shows up when you search its exact internal name.
  4. Click Install.
  5. This one is currently testing-only: turn on testing builds for it in the installer before it will show up.
