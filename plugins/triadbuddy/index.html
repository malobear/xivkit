About TriadBuddy

Triple triad solver, NPC matches only.

  • highlights next move during mini game
  • evaluates all deck presets before match
  • deck optimizer for NPC
  • adds more details to card collection window

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for TriadBuddy, and click Install.
