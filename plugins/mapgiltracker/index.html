About FATE/Map Gil Tracker

This plugin aims to simplify gil tracking for FCs who use FATEs/Maps as fundraising events! Simply install it, enable it, and it'll automatically track every chest or sack opened and calculate how much gil each person owes.

Can you install it?

Not right now. FATE/Map Gil Tracker was last built for Dalamud API 9, and current Dalamud is API 15, so the installer doesn't list it at all. It will come back if the author updates it. In the meantime, the similar plugins below do work.
