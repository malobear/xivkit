FFXIV Plugins

Dalamud plugins I actually use. Handy to have in one place when I'm recommending them to someone.

These are third-party client plugins run through Dalamud, not officially supported by Square Enix. Install and use at your own judgment. Anything tagged experimental isn't in Dalamud's default plugin directory; you add it under Dalamud Settings → Experimental → Custom Plugin Repositories using the repo/URL linked below.

Get Started

  • DalamudPlugin framework for FFXIV client tools and mods. Install this first, everything else on this page runs through it
  • PenumbraRuntime mod loader, applies texture/model mods without touching game files. Custom repo, not in the default plugin directory
  • GlamourerChanges your character's outside appearance using Penumbra mods, what Glamaholic plates apply through. Custom repo, not in the default plugin directory
  • The Reni GuideBeginner-friendly walkthrough for setting up Penumbra and Glamourer to mod your character's appearance

Housing & Decoration

  • Burning Down The House (BDTH)Gizmo-based housing item positioning, far more precise than the in-game editor. Custom repo, not in the default plugin directory.
  • LifestreamTravel to another world, data center, or house with a single command. Custom repo, not in the default plugin directory

Glamour

  • GlamaholicSave and swap glamour plates. Import looks straight from Eorzea Collection or someone else's export, try them on, and apply via Glamourer. In the default plugin repo but hidden from browsing, so search the exact name to install

Mods

  • XIV Mod ArchiveBiggest free mod repository: glamour, gear, and animation mods, installed via Penumbra
  • HeliosphereSecond mod source/manager I check when Mod Archive doesn't have what I'm looking for
  • Glamour DresserPaid mod marketplace. I don't usually pay, but a lot of creators unpaywall mods after a while, so I browse their Patreons for stuff that's gone free
  • Compress YourselfStep-by-step guide to compressing mod textures for Lightless/PlayerSync. Keeps synced mod sizes down

Chat & UI

  • Chat 2Complete in-game chat window rewrite: unlimited tabs, better filtering, RGB channel colors, unread counts. A must-have
  • Umbra XIVFully customizable toolbars and 3D world markers. In the default plugin repo but hidden from browsing, so search the exact name to install

Social & Friends

  • Better Friend ListCross-server friend list with FC-style login/logout notifications. The other person needs it installed too for you to see theirs

Inventory & Economy

  • Allagan ToolsCross-storage inventory search and filtering across characters, retainers, and the Free Company chest, plus craft planning and marketboard integration right in tooltips. In the default plugin repo but hidden from browsing, so search the exact name (InventoryTools) to install
  • Allagan MarketTracks retainer market listings, sales, and undercutting across every character at once. In the default plugin repo but hidden from browsing, so search the exact name to install
  • Price InsightShows NQ/HQ marketboard prices and the most recent sale directly on an item's tooltip on hover, pulled from Universalis. In the default plugin repo but hidden from browsing, so search the exact name to install
  • StackSellPriceShows a full stack's vendor sell price on the tooltip instead of just one unit, so you don't have to do the multiplication yourself before deciding to vendor a pile of materials. In the default plugin repo but hidden from browsing, so search the exact name to install
  • RepairMeReminds you when gear needs repairing or still has materia to extract before you get rid of it. In the default plugin repo but hidden from browsing, so search the exact name to install
  • Simple TweaksHuge, individually toggleable grab-bag of quality-of-life tweaks; several touch inventory, retainers, and tooltips directly. In the default plugin repo but hidden from browsing, so search the exact name to install

Plugin Discovery & Publishers

  • Dalamud Plugin BrowserBetter search/browse UI for what's available in the main plugin repo than Dalamud's own in-game list
  • Puni.shPlugin studio/publisher I pull from a lot: Artisan, AutoRetainer, Pandora's Box, and more. Their repo goes under Dalamud's Experimental settings.
