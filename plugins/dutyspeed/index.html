About DutySpeed

A simple speedrun timer for FFXIV duties.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for DutySpeed, and click Install.
