Lights, Camera, Action!

Save and load unlimited camera and lighting presets in Group Pose

About Lights, Camera, Action!

This plugin lets you save unlimited camera & lighting configurations/presets in Group Pose at a time, vastly improving over the vanilla feature which lets you save only one of each.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Lights, Camera, Action!, and click Install.
