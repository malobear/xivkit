DelvUI

A modern HUD replacement built for customization.

About DelvUI

DelvUI provides a highly configurable HUD replacement and is highly inspired by ElvUI from WoW

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for DelvUI, and click Install.
