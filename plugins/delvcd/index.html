About DelvCD

DelvCD provides highly customizable UI elements that can be used to track cooldows, status and more with configurable conditions.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for DelvCD, and click Install.
