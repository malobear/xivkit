About Moonbase Omega

Plays chat messages sent in Cosmic Exploration via DECtalk (the TTS used in Moonbase Alpha).

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Moonbase Omega, and click Install.
