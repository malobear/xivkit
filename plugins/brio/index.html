About Brio

Brio is a suite of tools that gives you advanced control to edit and pose actors during GPose.

  • Advanced actor posing
  • While animating
  • Overlay and graphical posing modes
  • Creation of up to 239 G-Pose actors
  • Creation of custom lights
  • Spawn and edit any visual object, Furniture or VFX in the game
  • Supports integration with Penumbra & Glamourer
  • Offline import and export of MCDF files onto G-Pose actors
  • Make and paly animations with Vivacity. The animation Timeline
  • Play XAT .xcp camera files
  • Play/Blend animations of GPose actors
  • Control Time/Weather in both the Overworld and GPose
  • Change the active festivals and apply up to 8 at once
  • Add/Remove Status Effects of GPose actors

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Sea of Stars repository addresshttps://raw.githubusercontent.com/Ottermandias/SeaOfStars/main/repo.json
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Brio, and click Install.

Brio comes from the Sea of Stars repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
