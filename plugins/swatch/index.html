About Swatch

a server info bar addon to display swatch internet time

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings, open the Experimental tab, and turn on Get plugin testing builds. This plugin is only released as a testing build, so it won't show up in the installer until that setting is on.
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Swatch, and click Install.
