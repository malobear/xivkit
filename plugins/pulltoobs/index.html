About PullToOBS

A Dalamud plugin that automatically controls OBS recording during FFXIV encounters. Captures replay buffer before pulls and full encounter recordings via OBS WebSocket v5. Supports quick-save hotkey for on-demand replay buffer clips. Use /pulltoobs or /pto to configure.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings, open the Experimental tab, and turn on Get plugin testing builds. This plugin is only released as a testing build, so it won't show up in the installer until that setting is on.
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for PullToOBS, and click Install.
