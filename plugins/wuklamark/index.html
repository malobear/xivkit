WukLamark

Create custom map markers on the map/minimap! Like <flag> but permanent.

About WukLamark

Allows players to create and manage persistent custom map markers across Eorzea. Whether it's a favorite GPose spot, a venue you want to revisit, or any interesting location, WukLamark lets you drop a map marker that appears seamlessly on both your main map and minimap. Features: - Customizable game icons and shapes for map markers (with optional icon tinting). - Custom map marker icons. > To add a custom icon, open the WukLamark window and click on 'Upload a new custom icon'. - Per-marker icon/shape sizes. - Organize map markers into groups (with map marker import/export). - Cross-character sharing configurations. - Crossworld markers. - Add personal notes for context. - Import/export one or multiple map markers with friends. - Templates for quick map marker creation with predefined properties. Think of it as dropping a flag on the map but persistent.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins and search for WukLamark. This plugin is hidden from the installer's browse list, so it only shows up when you search its exact internal name.
  4. Click Install.
