How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Puni.sh (asuna) repository addresshttps://puni.sh/api/repository/asuna
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for HuntAlerts, and click Install.

HuntAlerts comes from the Puni.sh (asuna) repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
