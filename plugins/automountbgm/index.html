About AutoMountBgm

Some mounts have really cool BGM tracks (Cruise Chaser FTW) while others are almost sickening in how much you hear them. It's annoying to keep needing to use /mountbgm, but now you won't have to - just let the plugin do it for you!

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for AutoMountBgm, and click Install.
