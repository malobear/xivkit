About Discord Rich Presence

Show your zone, job, level, name, and world in your Discord status.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Discord Rich Presence, and click Install.
