About Title Roulette

Allows you to pick any number of titles, setting a random one each time you use "/ptitle" or "/ptitle groupName".

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Title Roulette, and click Install.
