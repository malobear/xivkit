XIVWindowResizer

Game window resizing plugin. Ever wanted to take 8K screenshots on 144p screen? Now you can.

About XIVWindowResizer

Set your game window to arbitrary size not limited by your display resolution. Mostly useful for taking high-resolution screenshots without going fullscreen and using DSR/FSR. Requires borderless or windowed mode.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for XIVWindowResizer, and click Install.
