EchoXIV

Bidirectional chat translation in Dalamud with auto-failover. / Traducción bidireccional de chat en Dalamud con failover automático.

About EchoXIV

EchoXIV is a chat translation tool for FFXIV. It translates both incoming and outgoing chat messages so you can communicate more naturally with players who use other languages. Key Features: - Bidirectional chat translation for incoming and outgoing messages. - Configurable reading and writing languages. - Multiple translation engines (Google, Papago, LibreTranslate, Yandex, Local AI) with configurable fallback and automatic primary recovery. - Integrated Dalamud chat window for translated messages. [Español] EchoXIV es una herramienta de traducción de chat para FFXIV. Traduce mensajes entrantes y salientes para que puedas comunicarte de forma más natural con jugadores que usan otros idiomas. Características: - Traducción bidireccional para mensajes entrantes y salientes. - Idiomas de lectura y escritura configurables. - Múltiples motores de traducción (Google, Papago, LibreTranslate, Yandex, IA local) con respaldo configurable y recuperación automática del principal. - Ventana integrada de Dalamud para mensajes traducidos.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for EchoXIV, and click Install.
  4. This one is currently testing-only: turn on testing builds for it in the installer before it will show up.
