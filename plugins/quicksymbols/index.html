About QuickSymbols

Adds a Quick Symbols button beside the chat mode selector and other text inputs.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for QuickSymbols, and click Install.
