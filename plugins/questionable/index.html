About Questionable

A small quest helper plugin designed to automatically do your quests for you where possible. Utilizes navmesh to automatically travel to all quest waypoints and (attempts to) complete all steps along the way (excluding dungeons, single-player duties and combat).

Not all quests are supported.

Required Plugins: vnavmesh, TextAdvance, Lifestream

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Puni.sh repository addresshttps://love.puni.sh/ment.json
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Questionable, and click Install.
