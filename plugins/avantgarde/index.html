About Avant-Garde

This plugin is a crowdsourced project, aiming to provide a comprehensive list for all hint categories. See the github page for information on how you can contribute. Open the Fashion Report window to get started!

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Avant-Garde, and click Install.
