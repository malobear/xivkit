Auto-recreate your Party Finder after reco or datacenter switch

About NalaPF

Captures your PF configuration and automatically recreates it after a disconnect or datacenter switch.

Commands: /pfr

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    https://puni.sh/api/repository/nala
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for NalaPF, and click Install.

NalaPF comes from the Puni.sh (nala) repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
