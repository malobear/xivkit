GentleTouch Not in installer

Create vibration patterns for the controller and specify triggers to make it vibrate.

About GentleTouch

You need to configure patterns and triggers before it will work, open the configuration window to do that.

For DualSense/Shock4 support, the controller needs to be connected wired (same as the game's) and there can only be one of a type connected (e.g., only one DualSense, not two).

Currently supported triggers are:

  • Cooldowns
  • Near Aether Current

Can you install it?

Not right now. GentleTouch was last built for Dalamud API 9, and current Dalamud is API 15, so the installer doesn't list it at all. It will come back if the author updates it. In the meantime, the similar plugins below do work.
