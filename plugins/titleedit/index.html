Title Edit

Create, share, and shuffle custom title and character select screens for FFXIV.

About Title Edit

Create your own custom title or character select screen of your favorite location in-game, and open the game right up to that spot every time. Includes a number of preinstalled title and character select screen presets for you to use or get inspiration from, and an easy to use importer to use presets that others have shared! Character select presets support recording your last visited location, per character display setting and even displaying yourself on a mount.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Title Edit, and click Install.
