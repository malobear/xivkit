About Wahbuttons

Floating button windows that run any chat command. Lay buttons out in a column, a row or a grid, lock a window in place, make it see-through, and toggle it with /wahbuttons.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Puni.sh (wah) repository addresshttps://puni.sh/api/repository/wah
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Wahbuttons, and click Install.

Wahbuttons comes from the Puni.sh (wah) repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
