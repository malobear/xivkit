Why it's on my list

Huge, individually toggleable grab-bag of quality-of-life tweaks; several touch inventory, retainers, and tooltips directly. In the default plugin repo

About Simple Tweaks Plugin

A collection of Quality of Life tweaks. Aiming to improve the experience without changing anything drastically. All changes are toggleable, with everything disabled by default. Visit the Repo for a full list of tweaks. (Globe icon below)

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins, search for Simple Tweaks Plugin, and click Install.
