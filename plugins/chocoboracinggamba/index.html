About Chocobo Racing

Host live Chocobo Racing events at your venue with zero manual bookkeeping. Bets are captured from party and alliance chat automatically, player banks track every balance, and payouts are calculated at the click of a button. Run 2-10 chocobos with custom track lengths, odds, and branded chat messages. Full race history and profit/loss reporting included. Spectators can watch live and your players can place bets online with a PIN with the brand new webview feature.

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. Type /xlsettings and open the Experimental tab. Under Custom Plugin Repositories, paste this address, click the + button, then the save button.
    Puni.sh (oof-games) repository addresshttps://puni.sh/api/repository/oof-games
  3. Type /xlplugins to open the plugin installer.
  4. Open All Plugins, search for Chocobo Racing, and click Install.

Chocobo Racing comes from the Puni.sh (oof-games) repository, not Dalamud's official list. Dalamud's team has not reviewed it. Only add repositories you trust, and remove the repository again if you stop using its plugins.
