Character Panel Refined

Refine the character panel to display only useful information like crit and direct hit chance

About Character Panel Refined

Character Panel Refined cuts away useless information from the character panel, while adding useful stats like critical hit and direct hit percentages as well as estimates damage output to allow for easier comparison of gear.

Screenshots

How to install

  1. Install XIVLauncher with Dalamud and start the game through it.
  2. In game, type /xlplugins to open the plugin installer.
  3. Open All Plugins and search for CharacterPanelRefined. This plugin is hidden from the installer's browse list, so it only shows up when you search its exact internal name.
  4. Click Install.
